# Pulse — Windows desktop browser with integrated VPN

**Версия проекта:** 1.0.0  
**Платформа сборки:** Windows 10/11 x64  
**Технологии:** Electron, Chromium, sing-box

Pulse — тестовый настольный браузер с тёмным интерфейсом и встроенным VPN-клиентом sing-box. VPN-маршрутизация относится к сессии браузера, а не ко всему Windows.

## Быстрый путь для пользователя

Если вы не программист, откройте файл `ИНСТРУКЦИЯ_GITHUB_И_УСТАНОВКА.md` (также приложена отдельным DOCX к архиву). Там пошагово описано:
1. создание GitHub-репозитория;
2. загрузка файлов;
3. запуск GitHub Actions;
4. скачивание `Pulse-Setup-1.0.0.exe`;
5. установка Pulse и добавление подписки.

## Сборка локально на Windows

1. Установите Node.js 20+ LTS.
2. Откройте PowerShell в папке проекта.
3. Выполните:
   `Set-ExecutionPolicy -Scope Process Bypass; .\\build-windows.ps1`
4. Установщик появится в `dist\\Pulse-Setup-1.0.0.exe`.

Скрипт скачивает официальный Windows x64 архив sing-box, устанавливает npm-зависимости и запускает electron-builder.

## GitHub Actions

Workflow расположен в `.github/workflows/build-windows.yml`. Он запускается после загрузки проекта в ветку `main` или вручную из вкладки **Actions**. Готовый установщик публикуется как artifact `Pulse-Windows-Installer`.

## Что входит в текущий прототип

- Chromium/Electron окно браузера.
- VPN-подключение через sing-box.
- Импорт распространённых VLESS, VMess, Trojan, Shadowsocks URI.
- Импорт Base64-списков URI, базовых Clash YAML и sing-box JSON outbound.
- Ручное и периодическое обновление URL-подписки.
- Автоподключение при запуске.
- Переключение узла через Clash API sing-box.
- Небольшой встроенный список рекламных/трекерных доменов.
- Ограничение WebRTC non-proxied UDP.

## Ограничения и безопасность

Это **не готовый к коммерческому выпуску и не прошедший независимый аудит продукт**.

- Полноценный Windows Firewall/WFP Kill Switch отсутствует.
- Браузерный прокси не гарантирует защиту всех сетевых подсистем Windows/Electron.
- Защита WebRTC является ограничением UDP, а не полной гарантией отсутствия утечек.
- Блокировщик рекламы использует небольшой статический список.
- Импорт Clash/sing-box не сохраняет сложные правила, группы и маршрутизацию исходной подписки.
- Совместимость селектора с API конкретной версии sing-box требует проверки на реальном сервере.
- Подписка сохраняется в локальном файле настроек в открытом виде.
- Установщик пока не подписан цифровым сертификатом; Windows может показать предупреждение SmartScreen.

Перед использованием проверьте приложение на тестовой подписке, проверьте внешний IP и DNS. Не считайте Pulse гарантией анонимности или полной защиты от утечек.
